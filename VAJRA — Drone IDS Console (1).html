Connect your drone system

      
This console runs entirely on simulated data until you point it at real services. Nothing here is wired to a backend yet — these are the contracts to implement.


      

        
1 · Raspberry Pi 5 → console, telemetry ingest

        
Your Pi 5 reads MAVLink off the flight controller (via pymavlink or mavsdk) and forwards a compact JSON frame at 5–10 Hz. Point connectTelemetry() in the source (search "TODO: connect") at your bridge's WebSocket or REST URL.

        
WS wss://your-bridge-host/telemetry

2 · Detection model output → console

        
Your two-stage pipeline (anomaly flagger + attack-category classifier) posts a result per flagged window. Keep evidence as raw feature deltas — that's what fills the "why flagged" view instead of a bare AI verdict.

        
POST /api/detections

        {
  "event_id": "evt_0001",
  "window_start": 1758700000000, "window_end": 1758700004000,
  "category": "gps_spoofing",
  "stage1_confidence": 0.93,
  "stage2_confidence": 0.88,
  "severity": "critical",
  "evidence": {
    "gps_jump_m": 340, "reported_speed_vs_derived_ms": 21.4,
    "sat_count_drop": 5, "hdop_delta": 3.2
  },
  "affected": ["gps", "mavlink_heartbeat"]
}
      


      

        
3 · Evidence hashing & blockchain anchor

        
This console already computes a real SHA-256 over each event record in-browser (see Evidence tab) using crypto.subtle.digest. Anchor that digest with your chain of choice and return the reference below.

        
POST /api/evidence/anchor

        { "event_id": "evt_0001", "sha256": "…",
  "tx_ref": "0x…", "chain": "polygon-testnet",
  "anchored_at": 1758700010000, "status": "confirmed" }
      


      

        
4 · Storage

        
The plan calls for Supabase as the backing store for sessions, telemetry snapshots, alerts and reports. This build keeps state in the browser only (per-viewer) so it runs standalone for a demo; swap the local store object for Supabase reads/writes at the same three call sites (telemetry tick, new alert, report generation) once your project is provisioned.
